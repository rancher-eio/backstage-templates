# EIO

EIO services, and how to get access to them.

- [Services](services.md) is the list: dashboards, logs, Vault, this portal, and
  the address for each one.
- [Repositories](self-service-repositories.md) covers how a repository request
  becomes a real repository.
- [Vault secrets](vault-secrets.md) lists the shared credentials a repository can
  be granted, and how to read each one in a workflow.

Anything you need from EIO starts here rather than in a ticket. A request opens
a pull request for review, you get a tracking issue with that pull request
linked from it, and the resources exist a few minutes after it merges.
