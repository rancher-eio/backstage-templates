# EIO

EIO services, and how to get access to them.

- [Services](services.md) is the list: dashboards, logs, Vault, this portal, and
  the address for each one.
- [Vault secrets](vault-secrets.md) lists the shared credentials a repository can
  be granted, and how to read each one in a workflow.
- [How self-service works](how-it-works.md) explains what self-service means
  here, what happens after you press Create, and what each piece is for.

This portal is the way into the platform EIO runs, rather than a ticket or a
question in Slack. A request opens a pull request for review, you get a tracking
issue with that pull request linked from it, and the resources exist a few
minutes after it merges.
